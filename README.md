# Akash K A - AI/ML Portfolio

A modern, responsive portfolio website showcasing my work as a Computer Science student specializing in AI/ML Engineering. Built with Django and featuring a GitHub-inspired dark/light theme.

## 🎯 Overview

This portfolio serves as a comprehensive digital presence highlighting my technical skills, projects, achievements, and professional journey in AI/ML Engineering. The site features a clean, professional design with smooth animations and full responsiveness across all devices.

## ✨ Key Features

### 🏠 Home Section
- Dynamic hero section with animated stats counter
- Interactive code window display
- Professional contact information bar
- Social media integration (GitHub, LinkedIn, LeetCode)

### 💻 Technical Skills Display
Three categorized skill sections:
- **Programming Languages** - Visual progress bars showing proficiency levels
- **AI/ML Stack** - Tag-based display of ML frameworks and tools
- **Web & Tools** - Development tools and technologies

### 🚀 Projects Showcase
- Grid layout of featured projects with status indicators (Active/Deployed/Completed)
- Technology tags for each project
- Interactive detail modal with comprehensive project information
- Direct links to GitHub repositories

### 🏆 Achievements & Education
- Timeline-style achievement cards with icons
- Educational background display
- Certification badges

### 📬 Contact System
- Integrated contact form with Django backend
- Success message notifications
- Direct contact information display
- Professional social media connections

### 🔐 Authentication System
- User registration and login functionality
- Role-based access control
- Admin dashboard for content management

### 🎨 Design Features
- GitHub-inspired theme (light/dark mode toggle)
- Smooth scroll animations
- Back-to-top button
- Mobile-responsive navigation menu
- Interactive project modals

## 🛠️ Technology Stack

### Backend
- **Framework**: Django 5.2.10
- **Database**: PostgreSQL
- **Authentication**: Django built-in auth system
- **Environment**: Python-decouple for secure configuration

### Frontend
- **HTML5** with Django templating
- **CSS3** with custom properties for theming
- **JavaScript** for interactivity
- **Font Awesome 6** for icons
- **Google Fonts** (Inter font family)

### Key Integrations
- Django Admin panel for content management
- Contact form with database storage
- Dynamic content loading from database
- Resume PDF download functionality

## 📂 Project Structure

The project follows Django best practices with:
- Separate app architecture
- Template inheritance system
- Static files organization
- Environment-based configuration
- Database migration management

## 🔒 Security Features

- Environment variables for sensitive data
- CSRF protection
- Secure password hashing
- Role-based access control
- SQL injection prevention

## 🎨 Theme System

Implements a sophisticated dark/light theme system:
- GitHub-inspired color scheme
- Persistent theme selection using localStorage
- Smooth transition animations
- High contrast and accessibility considerations

## 📱 Responsive Design

Fully responsive across all devices:
- Desktop (1200px+)
- Tablet (768px - 1024px)
- Mobile (480px - 768px)
- Small mobile (<480px)
